# ⚡ DarkSage Cyber Arsenal

A curated cybersecurity resource library — tools, platforms, labs, and 
YouTube channels for offensive security learning.

🌐 **Live site:** [muhseenmk.github.io/cyber-arsenal](https://muhseenmk.github.io/cyber-arsenal/)

---

## What This Is

A personal collection of resources I've gathered while learning cybersecurity. 
Everything here is something I've either used, plan to use, or that comes 
recommended by experienced practitioners.

No subscriptions. No paywalls. Just free resources, organised.

## Why I Built This

I kept losing track of good resources — bookmarks scattered across browsers, 
tabs left open for weeks, recommendations lost in old chats.

So I built this. One place for everything I use or plan to use.

If it helps someone else learning cybersecurity, even better.

---

## Tech

- Pure HTML, CSS, and JavaScript
- No frameworks, no build tools
- Single file (`index.html`)
- Hosted on GitHub Pages
